# Olist ELT Pipeline

A batch ELT pipeline built on the Olist Brazilian e-commerce dataset:
PySpark -> Snowflake -> dbt -> Airflow, with CI via GitHub Actions.

**Status:** MVP in progress.

## Dataset

[Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce) (Kaggle).
The raw files are not included in this repo. Download them and place the CSVs in `data/raw/`.
